# 📤 筆記線上編輯與上傳指南

本知識庫已設定好免安裝任何工具的**全網頁式編輯與上傳流程**。無論您身在何處、使用哪台電腦，只要打開瀏覽器就能直接在網頁上更改或上傳筆記！

---

## ✏️ 1. 如何直接在網頁上修改既有筆記？

在瀏覽本站的**任何一篇筆記或科目首頁**時：

1. 滑動到頁面最下方，會看到 **「✏️ 在 GitHub 上編輯此頁」** 按鈕。
2. 點擊後，瀏覽器會直接在新分頁開啟 GitHub 的線上 Markdown 編輯器。
3. 直接在網頁中修改文字、補充內容或修正筆記。
4. 修改完畢後，點擊右上角綠色的 **「Commit changes...」**。
5. **完成！** GitHub Actions 會在 1 分鐘內自動打包，線上網站隨即更新。

---

## 📁 2. 如何直接在網頁上傳 `.md` 筆記檔案？

如果您已經在電腦中寫好了一份 `.md` 筆記，想要直接上傳到網站中：

1. 打開您的 GitHub 儲存庫網址：
   `https://github.com/411335070/ai-hw/tree/main/docs/notes`
2. 點擊進入您要上傳的科目資料夾（例如：`database-programming`）。
3. 點選右上角的 **「Add file」 $\rightarrow$ 「Upload files」**。
4. 將您電腦中的 `.md` 檔案拖曳進上傳方框中。
5. 點擊底部的 **「Commit changes」**。
6. **完成！** 該筆記檔案會自動納入該科目，網站會在 1 分鐘內自動更新上線。

---

## ⚡ 3. 本機運行時的即時新增方式

如果您目前在自己的電腦上運行本地預覽：
* **方式一（檔案拖曳）**：直接將 `.md` 筆記拖入 `docs/notes/<科目名稱>/` 目錄中，網站立刻熱重載。
* **方式二（指令生成）**：
  在專案目錄終端機執行：
  ```powershell
  node scripts/new-note.js <科目名稱> "<筆記名稱>"
  ```
  例如：
  ```powershell
  node scripts/new-note.js database-programming "關聯模型與SQL初探"
  ```
